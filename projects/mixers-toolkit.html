Book · Focal Press, 2011

Pro Tools 9: The Mixer’s Toolkit

With Kevin Ward. Focal Press, 2011. ISBN 978-0-240-81871-9.

The second one

Where the first book was about repairing and assembling performances — editing, pocketing, pitch — this one is about the stage after that. Mixing: the point at which a set of recorded parts has to be turned into a record that somebody would choose to listen to.

It was written for Pro Tools 9, which dates it precisely and, in one specific way, usefully. Version 9 was the release that untethered Pro Tools from Avid’s own hardware. For the first time you could run it on an ordinary interface, which meant the audience for a mixing book stopped being people with a studio and started being anybody with a laptop.
